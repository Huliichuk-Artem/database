# Kittens database

Датабаза що дозволяє додавати, переглядати, оновлювати та видаляти кошенят у PostgreSQL

node db.js help - список всіх команд  
node db.js list - показати всіх кошенят  
node db.js add <імя> <порода> <окрас> <тип_шерсті> <рівень_енергії> - додати кошеня  
node db.js update <id> <рівень_енергії> - оновити рівень енергії кошеняти  
node db.js delete <id> - видалити кошеня
